# SecLab App Icon

为应用和套件入口制作轻量立体 PNG 图标。生成图像时必须同时使用 `$imagegen`；本 skill 负责 SecLab 视觉约束、资产落点、后处理和验收。

## 工作流

1. 阅读 `../../shared/brand/seclab-brand.md` 和 `references/visual-language.md`。
2. 阅读 `references/approved-family.md`，检查已确认图标的共同特征，避免新图标脱离视觉家族。
3. 内置应用读取 `references/app-icon-map.md`；套件从 `suite.yaml`、README 和实际功能中提炼单一视觉隐喻。
4. 生成前先写出四项设计简报：
   - 主对象：用户第一眼必须识别的对象。
   - 辅助信号：用于表达动作或状态，最多一个。
   - 层级关系：哪个对象必须最大、最亮或位于视觉中心。
   - 禁止隐喻：容易误解为其它产品、设备或通用符号的造型。
5. 检查目标仓库的既有图标、名称和资产路径，避免重复创建或覆盖未确认的文件。
6. 使用 `$imagegen` 分别生成至少两版 `1024x1024` 候选稿。两版必须改变对象结构或层级关系，不能只换颜色、材质或观察角度：
   - 使用轻量立体风格。
   - 主体居中、轮廓完整、四周留足空间。
   - 不生成文字、徽章底板、投影到地面的场景或水印。
   - 需要透明背景时遵循 `$imagegen` 的内置生成加本地去背景流程。
7. 按 `references/visual-language.md` 的淘汰条件逐张检查。第一版不自动成为最终稿；不合格候选必须废弃或定向重生成。
8. 对合格候选完成去背景和规范化，再同时查看 256px、64px、40px。只比较原始大图不算完成设计评审。
9. 选择语义最直接、层级最清晰、40px 下最稳定且最接近已确认视觉家族的一版。
10. 运行导出脚本，将候选稿规范化为最终资产：

```bash
uv run .agents/skills/seclab-app-icon/scripts/prepare_icon.py \
  <source.png> \
  <destination/icon.png> \
  --preview-dir <temporary-preview-directory>
```

11. 使用 `view_image` 再次检查最终 256px 图标及 64px、40px 预览。发现含义模糊、层级丢失、边缘脏污或缩略图不可读时，回到生成阶段调整，不用锐化或堆叠细节掩盖问题。
12. 更新消费方清单或图标 URL，并运行目标仓库要求的格式化、测试和构建命令。
13. 删除临时候选稿和预览目录。消费仓库只保留最终 `256x256 RGBA PNG`。

## 资产落点

- 内置应用：`frontend/public/images/apps/<app-id>.png`。
- Compose 套件：`suites/<分类>/<suiteId>/package/<version>/assets/icon.png`。
- 文件名使用小写字母、数字、点、短横线或下划线；内置应用默认使用 `<app-id>.png`，套件固定使用 `icon.png`。
- 不把业务图标存入 `seclab-skills`；skill 仓库只保存规范和工具。

## 硬性规则

- 最终文件必须是 `256x256`、RGBA、带透明通道的 PNG。
- 图标主体不得触碰画布边缘；最终安全边距至少 16px。
- 四角必须透明，主体不能依赖方形、不透明或渐变背景板成立。
- 使用一个主对象和最多一个辅助信号，避免小文字、复杂场景、密集零件和多对象叙事。
- 有管理、控制、中心、主从含义时，必须通过尺寸、位置和强调色建立明显层级，不能让所有对象同权。
- 至少生成两版结构不同的候选，并记录废弃候选的具体原因。
- 保持专业、安全基础设施和工程工具气质；禁止骷髅、黑客人物、字符雨、武器、霓虹 HUD、游戏道具感和夸张拟物。
- 不复制第三方商标、产品 logo 或受保护角色。只有用户明确要求且仓库确认拥有使用权时才可使用品牌标识。
- 不把应用或套件 PNG 加入 `@seclab-dev/icons`；该包只承载通用 UI SVG。
- 不保留 1024px 母版、色键源图或未采用候选稿，除非用户明确要求。

## 完成标准

- 图标语义与应用或套件核心功能一致。
- 主对象、辅助信号和层级关系符合生成前设计简报。
- 浅色、深色背景下轮廓和层次都清晰。
- 256px 无明显色键残边；64px 和 40px 仍能识别主对象。
- 与 `references/approved-family.md` 中已确认图标具有一致的材质、光源、明度和视觉重量。
- `prepare_icon.py` 校验通过。
- 清单或应用目录引用最终 PNG 的稳定 URL，不依赖前端固定拼接文件名。
